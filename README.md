Important!
==========

This library is still in development
and some features might not be well implemented or documented to be helpful
for everyone, so use it if you know what you are doing. Worst case scenario - 
it just won't work.

In theory this should work with any Unity game using Wwise middleware 
that's moddable with BepInEx - but this hasn't been tested outside RoR2,
so hook compatibility with other games' Wwise integration isn't guaranteed.
